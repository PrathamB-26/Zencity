# Git Automation Rule

- Automatically pull any remote updates before making changes if needed.
- After completing any set of changes, creations, or fixes, automatically stage all modified and new files (`git add .`), create a descriptive commit (`git commit -m "..."`), and push to the remote repository (`git push origin main` or current tracking branch).
- Do not ask for confirmation before staging, committing, or pushing changes. Execute these operations autonomously.
